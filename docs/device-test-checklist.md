# Physical-device acceptance checklist

Record device model, OS version, app commit, result, and a screenshot/video or exported-file hash.

- [ ] Capture 3 pages; adjust all four corners; retake page 2; reorder 3→1; PDF order is 3,1,2.
- [ ] Force auto-edge failure and complete a manual capture.
- [ ] Import EXIF rotations 1–8; preview and JPG/PNG/PDF are upright.
- [ ] Kill during a 3-page edit; relaunch; originals, order, rotations, and filters recover.
- [ ] Save through Android SAF / iOS Files, reopen, and compare page count/order.
- [ ] Cancel destination chooser and confirm draft remains with no success message.
- [ ] Export 2+ JPG and PNG pages; ZIP contains every numbered page.
- [ ] Compare small/standard/high dimensions and JPEG quality file sizes; inspect PDF DPI.
- [ ] Simulate full storage, revoked URI/provider, and share target unavailable.
- [ ] Decode screenshot, rotated QR, tiny cropped QR, multi-QR, and a no-QR image offline.
- [ ] Confirm live detections are deduplicated and never open automatically.
- [ ] Share one/multiple images into Android; share one image through signed iOS extension.
- [ ] Open http/https, mailto, and tel with/without installed handlers.
- [ ] Confirm text remains display-only and javascript/data/file/intent/custom schemes never open.
- [ ] Deny camera/photos, recover via Files, and inspect all messages with TalkBack/VoiceOver.
- [ ] Stress 50 high-resolution pages and profile peak memory/background interruption.
